# ConSol Monitoring

**Open source monitoring. Built from real-world experience. Shared with everyone.**

We are the monitoring team at **ConSol Software GmbH**, Munich, Germany. We develop and contribute to open source tools that help teams monitor their infrastructure, automate configuration, and operate monitoring at scale.

Our development is driven by practical customer requirements. We share the resulting tools, features, and knowledge with the community.

📚 **[Technical documentation](https://omd.consol.de)** · 🌐 **[Monitoring at ConSol](https://www.consol.de/monitoring)**

## Explore our monitoring ecosystem

| Project | What it does |
| --- | --- |
| **[OMD Labs](https://github.com/ConSol-Monitoring/omd)** | An integrated monitoring platform combining tools from the Nagios and Prometheus ecosystems, packaged for straightforward installation and maintenance. |
| **[SNClient](https://github.com/ConSol-Monitoring/snclient)** | A cross-platform monitoring agent written in Go, designed as a replacement for NSClient++. |
| **[Coshsh](https://omd.consol.de/docs/coshsh/)** | Automates the generation of monitoring configurations from infrastructure data. |
| **[Monitoring plugins](https://omd.consol.de/docs/plugins/)** | Checks for databases, networks, hardware, applications, and more. |
| **[Thruk](https://omd.consol.de/docs/thruk/)** | A monitoring web interface with multiple backends, dashboards, reporting, and a REST API. |
| **[Naemon](https://omd.consol.de/docs/naemon/)** | An open source monitoring core for checking systems and services. |
| **[Mod Gearman](https://omd.consol.de/docs/mod-gearman/)** | Distributes active Naemon checks across workers to scale monitoring. |
